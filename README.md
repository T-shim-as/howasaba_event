# ホワサバ スケジュール生成 (For R5/R4)

[![GitHub Pages](https://img.shields.io/badge/Demo-GitHub%20Pages-0284c7?style=flat-square&logo=github)](https://t-shim-as.github.io/howasaba_event/)
[![License](https://img.shields.io/badge/License-MIT-blue.svg?style=flat-square)](LICENSE)

スマートフォン戦略ゲーム「ホワイトアウト・サバイバル（ホワサバ）」の同盟幹部（R5/R4）向けスケジュール管理＆チャット用等幅テキスト出力Webアプリケーションです。

ゲーム内等幅チャット特有の制約（改行上限10回、全角16文字幅の自動折り返し、サロゲートペアによる文字幅崩れ）を解決し、Firebase Cloud Firestoreによる複数幹部間のリアルタイム共同編集を実現しています。

---

## 🌟 主な機能・特徴

### 1. ゲーム内等幅チャット仕様への完全最適化
- **改行10回制限の克服**: 本文の改行を使わず、行末の半角スペースによる自然折り返し（全角16文字幅）を活用した独自フォーマッタを搭載。
- **精密な文字幅計算**: Unicodeサロゲートペア・異体字セレクタ（絵文字・記号等）を考慮し、全角/半角の表示幅を計算。スマホ・PCを問わず絶対に崩れない表を出力。
- **リアルタイム警告バナー**: 1行16文字の折り返し超過や改行数上限（10回）の超過を自動検知し、コピー前に警告表示。
- **直接テキスト編集モード**: 自動生成されたテキストエリアを直接書き換え可能（特記事項やルールの追記に便利）。
- **日付自動計算**: 選択中の曜日に合わせてタイトルへ日付範囲（例: `[11/2～11/8]`）をワンタップ挿入。

### 2. 複数幹部でのリアルタイム共同編集 ＆ セキュリティ
- **Firestore リアルタイム双方向同期**: `onSnapshot` リスナーにより、他の同盟幹部が更新した内容を画面リロード不要で即座に自動反映。
- **編集中コンフリクトガード**: 自身がモーダル（イベント編集・項目編集等）を開いている最中は他者の更新を待機させ、作業中のデータ消失を防止。
- **安全な同盟アカウント認証**: SHA-256ハッシュ化によるクライアント認証。同盟名変更や移民時もアカウントIDをそのまま引き継ぎ可能。
- **パスワード変更 ＆ 旧セッション自動切断**: 幹部交代時にも安全にパスワードを変更でき、旧パスワードのまま開いている他端末を即時ログアウト。

### 3. モバイルファーストな操作性・UI/UX
- **1段ヘッダー設計**: スマートフォン画面でも折り返さないコンパクトなヘッダー。
- **ハンバーガーメニュー**: 日常のスケジュール編集操作と、バックアップ・パスワード変更等の管理操作を整理・分離。
- **8日間固定マトリクス**: 月曜から翌週月曜までの重なりを一目で俯瞰。
- **ダブり項目の記号統合（カスタマイズ対応）**: 複数イベントが重なったマスに `🔴` や `🔵` を自動割り当てし、凡例に統合表示。割り当て記号の順序はパレットから自由に変更可能。
- **二重のバックアップ体制**: JSONファイルでのエクスポート/インポート、初期テンプレート（定番20項目・主要12イベント）の即時展開。
