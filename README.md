# ホワサバ スケジュールマトリクス (同盟幹部用)

ホワイトアウト・サバイバル（ホワサバ）の同盟幹部向けスケジュール管理＆チャット用テキスト出力Webアプリケーションです。

---

## 🌟 主な機能

- **同盟ごとのクラウドDB同期**:
  - 「同盟アカウントID」と「パスワード」の2項目だけでアカウントを作成（同盟名変更やサーバー移動があってもそのまま継続利用可能）。
  - 盟主1人での管理はもちろん、幹部全員が同じID・パスワードでログインすることで編集内容を自動同期できます。
  - 「ログイン情報を保存する」チェックボックスにより、次回以降の自動ログイン・自動入力に対応。
  - クラウドDB未設定時でも、ブラウザのローカル模擬DBで即座に動作確認できます。
- **スケジュールマトリクス表 (月〜翌月 8日間固定表示)**:
  - Day 1: I(月) から Day 8: Ⅷ(月) までの8日間を固定表示。トグル切り替えの手間をなくし一目で把握可能。
  - アクション項目列を中央揃えに配置し、視認性を向上。
- **安心の安全設計（まっさらな初期状態 ＆ 初期テンプレート）**:
  - アプリの初期状態は完全なまっさらに設定。
  - 必要な場合はワンクリックで「初期テンプレート（定番20項目 ＆ 主要12イベント）」を一括展開可能。
  - 外部JSONファイル（`howasaba_schedule_preset.json`）や「インポート」機能からも安全に復元できます。
- **クリーンなイベント表示 ＆ 専用ポップアップでの並び替え**:
  - メイン画面はクリックするだけでON/OFFできるシンプルなバッジ（ドラッグハンドル等を撤去し誤操作ゼロへ）。
  - 「⚙️ イベント管理・並べ替え」モーダルから、▲▼ボタンやドラッグ＆ドロップで優先度・表示順を安全に変更可能。
- **アクション項目編集・並べ替え (自動保存)**:
  - 正式名と短縮名（全角2文字推奨）の編集、行の並び替え（ドラッグまたは ▲▼ ボタン）。
  - 入力・変更内容は各行の保存ボタンを押すことなくリアルタイムに自動保存されます。
- **データ管理 (インポート / エクスポート)**:
  - JSONファイルのダウンロード / 読み込み（バックアップ・別同盟への複製）
  - JSONテキストのコピー / 貼り付け復元
- **チャット用等幅テキスト出力 (ホワサバ10回改行制限 & 16文字自動折り返し対応)**:
  - ゲーム内チャットの「改行10回制限」と「全角16文字幅」に完全対応した自動スペース折り返しフォーマット。
  - 出力する曜日を **連続期間レンジバー（ドラッグ・2タップ・開始/終了プルダウン）** で直感的に選択可能（定型期間ボタン「月〜日」「火〜月」「月〜金」も完備）。
  - 同日・同項目のイベント重複時は **「🔴：イベントA&イベントB」の自動記号統合モード** と **複数行展開モード** を切り替え可能。
  - 空欄マスの文字を **「ー（ハイフン）」と「　（全角空白）」**、区切り線を **「｜（全角）」と「|（半角）」** から自由に切り替え可能。
  - **日付自動挿入ボタン**: 選択されている曜日の開始〜終了日（例: `[11/2～11/8]`, `[11/3～11/9]`）を自動計算し、タイトルへ即座に反映。
  - 改行（`↵`）・半角空白（`␣`）・全角空白（`□`）の可視化プレビュー機能付き。

## 🚀 無料でのリリース・公開手順 (GitHub Pages)

### 1. GitHubリポジトリの作成
1. [GitHub](https://github.com/) にログインし、「New repository」から新しいリポジトリを作成します（例: `howasaba_event` / Public推奨）。
2. 本フォルダの `index.html`、`howasaba_schedule_preset.json`、`README.md` をリポジトリにアップロード（または `git push`）します。

### 2. GitHub Pages の有効化
1. リポジトリの **Settings** > **Pages** を開きます。
2. **Branch** で `main`（または `master`）、フォルダを `/ (root)` に設定して **Save** をクリックします。
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でWebアプリが世界中に無料公開されます。

## ☁️ クラウドDB (Firebase Cloud Firestore) の無料セットアップ手順

複数の端末や幹部間でスケジュールをリアルタイム共有するための設定です（Googleアカウントで利用可能・完全無料・放置による一時停止なし）。

### 1. FirebaseプロジェクトとFirestoreの作成
1. [Firebaseコンソール](https://console.firebase.google.com/) にGoogleアカウントでアクセスし、「プロジェクトを作成」をクリックします（GoogleアナリティクスはOFFでOK）。
2. 左メニューの **構築** > **Firestore Database** を開き、「データベースの作成」をクリックします。
3. ロケーションを `asia-northeast1 (Tokyo)` に設定し、作成します。
4. Firestoreの **「ルール (Rules)」** タブを開き、以下のセキュリティルールを貼り付けて **「公開」** を押します。

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /alliances/{accountId} {
      allow read: if true;
      allow create: if !exists(/databases/$(database)/documents/alliances/$(accountId));
      allow update: if request.resource.data.password_hash == resource.data.password_hash;
      allow delete: if false;
    }
  }
}
```

### 2. Webアプリ設定値の取得とコードへの設定
1. Firebaseコンソール左上の **歯車アイコン（プロジェクトの設定）** > 全般 > マイアプリの「`</>`（ウェブ）」アイコンをクリックし、アプリ名（任意）を入れて登録します（Firebase Hostingのチェックは不要）。
2. 表示される `firebaseConfig` の中身（`apiKey`, `projectId` 等）をコピーし、`index.html` 内の定数 `FIREBASE_CONFIG` に貼り付けてデプロイします。

## 👥 利用方法

1. **同盟アカウントの作成**:
   - トップ画面の「✨ 新規アカウント作成」タブを選択。
   - 任意の「同盟アカウントID」（例: `ejy_schedule`）と「パスワード」を入力して作成。
2. **幹部メンバーへの共有（共同管理する場合）**:
   - 他の幹部に「サイトURL」と「同盟アカウントID・パスワード」を共有。
3. **日常の編集とバックアップ**:
   - ログイン中にイベントの並び替えや編集を行うと、リアルタイムで自動的にクラウドへ同期され、同時に開いている他端末にも即時反映されます。
   - ヘッダー右上の「📤 エクスポート」からいつでもJSONバックアップを手元に保存でき、イベント選択バーの「📥 インポート」から復元や初期テンプレート展開が可能です。
